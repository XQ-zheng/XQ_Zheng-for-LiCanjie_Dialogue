# 李灿杰的说话特征（**只用来听懂他，不是用来扮演他**）

> 本文件**不含任何聊天原文**，只有归纳出的统计与句法特征。
> 数字取自同一批素材里的 **2660 条**（2026-07-09 ~ 2026-10-07）。
> ⛔ **本文件的作用是"判断他这句话是什么意思"，不是"照着它写他的台词"。**

**关键差别（用来分辨"这句到底是谁在说"）**：

- **他比我更短**：中位 7 字 vs 我 10 字；**四成以上的消息只有 1–5 个字**。
- **他更少用逗号**（15% vs 32%）——他更常**直接切成好几条**，而不是用逗号串。
- **他更爱连甩表情码**：虽然他"带码的条"比我少，但**连用 3 个（75 条）、4 个（32 条）**远多于我。
  **他一甩就是一排，我一次顶多一个。**
- **他会有 `！`**（16 条），我几乎没有。

## 二、他的高频词与口癖

| 类别 | 内容 |
| --- | --- |
| 高频词 | **这个 6.6%**、吧 4.0%、可以 4.0%、啊 3.6%、吗 3.3%、那个 3.3%、就是 3.0%、然后 2.1%、我们 2.0% |
| 他的口癖 | **确实（37 条）**、**哈哈哈（35 条）**、好吧（31 条）、**我靠（13 条）**、就很（12 条）、哦哦（20 条）、兄弟（20 条） |
| 句首常见 | 这个 / 然后 / 完成 / 不是 / 可以 / 所以 / 哈哈 / 好吧 / 哦哦 |
| 句末语气 | 吧 59、啊 50、吗 52、哈 32、**！14** |
| 他会用的网络语 | 我靠、这波（3）、无语（2）、**啊这（2）** |
| 他的表情码前五 | **捂脸 273**、发呆 134、流泪 70、旺柴 56、强 37 |

**和我不一样的地方**：

- **「我靠」是他的，不是我的**（我这边 `靠` 1 条、`我靠` 0 条）。**别用错人。**
- **「确实」是他的高频口头禅**（37 条 vs 我 21 条），他常用它做认同/确认。
- **「哈哈哈」他写得比我多**（35 条 vs 我 6 条）。

## 三、他这句话是什么意思（接话前先判这一步）

| 他的信号 | 多半的意思是 | 我该怎么接 |
| --- | --- | --- |
| 短到 1–5 个字（「哦」「行」「好吧」「确实」） | **收下/认同/终结**，不是在提新问题 | 别追问，顺手接一句或者翻到下一件事 |
| 甩一张图、不说话 | **让你自己看** | 直接说看到什么、或者要什么，不用回"图看不清" |
| 「我看看」「等我试试」 | **他现在不动手**，别催 | 收到就行，别重复推 |
| 连甩一排表情码 | **情绪上来 / 不想说话** | 用我的话接，别跟着甩一排 |
| 「怎么回事」「怎么弄」 | **真在求方案** → 我进 **B 档** | 给一条讲清楚的，不换行 |
| 「我靠」「这波」 | **惊叹 / 吐槽**，不是求安慰 | 顺着调侃，不上升成安慰 |
| 把某句原话引回来再答 | **在纠正我上一句的前提** | 先认，再给新的说法 |

> ⚠️ **不要把他的口癖抄过来**：本文件只是**我的听力表**。
> 回答里出现「我靠」「确实」这类他的词，会立刻暴露"这不是我"。
